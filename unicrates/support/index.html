UniCrates support

Contact tausvokseoff@gmail.com or join the Discord community. Do not send passwords, card details, private issuer keys, activation identities or unredacted database configuration.

Installation problems

Include the Minecraft version, loader version, exact UniCrates filename, installation mode, steps to reproduce and a relevant log excerpt. Start with the installation guide. Confirm Fabric API is present for Fabric and that you have not combined alternative server JARs.

Purchase and downloads

After checkout, return to the product page and save your purchase-access file before closing the tab. Use “Open saved purchase access” on that page to reopen downloads during its 30-day access window. The license key is a separate download; store it securely with your purchase receipt. We do not automatically email license keys.

If you lose the access file or need downloads after it expires, contact us privately with your Paddle transaction reference or receipt. Do not buy again to retry a failed download. Never post your license key, purchase-access file or activation identity in a public issue.

Activation and host moves

Describe the activation error and include the result of /crate license after removing any private information. Stop the previous installation before requesting a move to a host with a different outgoing IP. Clients do not need the server license key.

Custom work

New Pro purchases do not include an individual animation service. Any separate custom work requires a separately agreed scope and price. Earlier written agreements remain valid.

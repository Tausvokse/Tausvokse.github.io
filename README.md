# Cellkeep on taushop.me

Cellkeep is the homepage: a browser tool for inspecting CSV conversion risks and exporting literal-text Excel files. Processing stays on the device.

- [Cellkeep source and documentation](https://github.com/Tausvokse/cellkeep)
- [UniCrates editions and purchase information](https://taushop.me/unicrates/)
- [Minecraft mod documentation](https://taushop.me/mods-wiki/)
